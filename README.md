# 睿度新人自學入口

繁體中文靜態網站示範版，包含新人學習地圖、公司知識庫與廠商聯絡簿

## 使用方式

下載 `index.html` 後以瀏覽器開啟即可預覽

## 目前範圍

- 學習地圖有 6 個主題、12 個教材單元與單選檢核題；答對後更新完成進度
- 完成記錄儲存在目前瀏覽器的 localStorage，不會跨裝置或跨使用者同步
- 沒有帳號登入、伺服器或資料庫
- 教材內的公司流程和規範皆是虛構示範，正式使用前須由公司負責人審核與改寫
- 廠商與窗口都是虛構範例，請勿當成實際聯絡資訊
- 此 repo 與 Pages 網站均為公開，禁止放入真實內訓、客戶或窗口資料
- GitHub Pages 網址：https://youngger9765.github.io/redutek-onboarding-hub/
